# ⚡ UpTech - Loja de Eletrônicos

Bem-vindo à vitrine virtual da **UpTech**! 

Este site foi criado para facilitar as vendas na nossa região. O cliente navega pelos produtos, escolhe o que quer e já é redirecionado direto para o WhatsApp com a mensagem pronta, sem precisar ficar copiando e colando.

## 📍 Região de entrega
- Barro Alto
- Mulungu
- Canarana

## 🛒 Produtos em destaque
- Fones de ouvido Bluetooth
- Relógios Digitais / Smartwatch
- Capinhas de celular (iPhone e Samsung)
- Cabos USB-C e Lightning
- Power Banks

As vendas são feitas exclusivamente via WhatsApp, garantindo um atendimento rápido e personalizado.

## 🚀 Tecnologias utilizadas
- HTML5
- CSS3 (Tema Dark/Modo Noturno)
- JavaScript (Integração com a API do WhatsApp)
